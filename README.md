## 🇸🇦 باللغة العربية

### 📝 وصف المشروع
تطبيق ذكي وخفيف للتحكم الكامل بتلفاز LG الذكي (webOS) عبر شبكة الواي فاي المحلية باستخدام بروتوكول `WebSockets`.

### ✨ الميزات الأساسية
* **الاقتران الآمن:** مصادقة الاتصال مع التلفاز وحفظ رمز الاقتران.
* **التحكم بالصوت والقنوات:** رفع وخفض الصوت، التنقل بين القنوات، وكتم الصوت.
* **التنقل والإدخال:** محاكاة أزرار الأسهم والكتابة المباشرة عبر الهاتف.

---

## 🇬🇧 English

### 📝 Project Description
A lightweight smart remote control application to manage LG webOS TVs over a local Wi-Fi network using `WebSockets`.

### ✨ Key Features
* **Secure Pairing:** TV authentication and session token management.
* **Media Control:** Volume adjustment, channel switching, and muting.
* **Navigation & Input:** D-pad navigation and direct text input from mobile.
