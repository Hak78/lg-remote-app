## 🇸🇦 باللغة العربية

### 📝 وصف المشروع
تطبيق ذكي وخفيف للتحكم الكامل بتلفاز LG الذكي عبر عدة وسائل اتصال لتوفير مرونة تامة واستخدام سلس.

### ✨ الميزات الأساسية
* **الاتصال المتعدد (Multi-Connection):** دعم الاتصال عبر **الواي فاي (Wi-Fi/webOS)**، **الأشعة تحت الحمراء (IR)**، و**البلوتوث (Bluetooth)**.
* **الاقتران الآمن:** مصادقة الاتصال مع التلفاز عبر الشبكة وحفظ رمز الاقتران.
* **الأشعة تحت الحمراء (IR Blaster):** إرسال الأوامر الأساسية المباشرة (تشغيل/إيقاف، رفع وخفض الصوت) دون الحاجة لشبكة إنترنت.
* **التحكم عبر البلوتوث (Bluetooth):** ربط الهاتف بالتلفاز للتحكم السريع والأجهزة الطرفية.
* **التنقل والإدخال:** محاكاة أزرار الأسهم والكتابة المباشرة عبر لوحة المفاتيح.

## 🇬🇧 English

### 📝 Project Description
A lightweight smart remote control application to manage LG TVs using multiple connection methods for ultimate flexibility.

### ✨ Key Features
* **Multi-Connection Support:** Control LG TVs via **Wi-Fi (webOS)**, **Infrared (IR)**, and **Bluetooth**.
* **Secure Pairing:** TV authentication and session token management over local network.
* **Infrared Blaster (IR):** Send direct basic commands (Power, Volume) without requiring a network connection.
* **Bluetooth Control:** Pair mobile devices for seamless local interaction.
* **Navigation & Input:** D-pad navigation and direct text input.
